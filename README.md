Descrição: Projeto desenvolvido em JavaScript para simular o checkout de uma loja virtual, calculando valores dos produtos e aplicando cupons de desconto.

Funcionalidades:

* Cálculo do subtotal e da quantidade de itens.
* Aplicação de cupons de desconto.
* Cálculo do valor final da compra.

Como executar: Com o Node.js instalado, execute node checkout.js no terminal.

Versionamento: O Git registra as alterações do código, enquanto as branches permitem desenvolver funcionalidades separadamente, evitando conflitos e facilitando o trabalho em equipe.
